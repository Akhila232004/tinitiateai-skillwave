# Getting Started

**Prereqs**: Node LTS, pnpm or npm.

**Create with Vite** and explore the project structure.

```ts
pnpm create vite@latest my-vue-app --template vue-ts
cd my-vue-app
pnpm install
pnpm dev
```
**Expected output:** You see the Vite+Vue starter. Stop with Ctrl+C; build with `pnpm build` and preview with `pnpm preview`.
