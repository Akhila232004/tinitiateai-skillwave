# Project Setup

Quick-start with **Vite** + Vue 3 and essential tooling.
- Install Node LTS and pnpm (or npm).
- Create project with Vite.
- Add ESLint/Prettier, Volar, and Pinia/Vue Router when needed.

```bash
# Create
pnpm create vite@latest my-vue-app --template vue-ts
cd my-vue-app

# Install & run
pnpm install
pnpm dev
```
**Expected output:** Dev server starts on http://localhost:5173 with a Vue 3 starter page.
