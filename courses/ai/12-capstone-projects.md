# Capstone Projects

Capstone projects help learners combine AI concepts into practical portfolio work. Each project should include problem framing, data or context, model workflow, evaluation, safety notes, and deployment thinking.

## Project 1: AI Study Assistant

Build an assistant that answers questions from course notes.

Core features:

- Upload or index lesson markdown.
- Retrieve relevant sections.
- Answer with citations.
- Say when the answer is not in the course content.
- Track helpful and unhelpful feedback.

Skills practiced:

- RAG.
- Prompting.
- Evaluation.
- User experience design.

## Project 2: Support Ticket Classifier

Build a system that classifies support tickets by topic, priority, and routing team.

Core features:

- Clean sample ticket data.
- Define labels.
- Train or prompt a classifier.
- Evaluate precision and recall.
- Show confidence and allow human correction.

Skills practiced:

- Problem framing.
- Data preparation.
- Classification.
- Monitoring and feedback loops.

## Project 3: Document Intelligence Pipeline

Build a workflow that extracts structured fields from invoices, resumes, contracts, or reports.

Core features:

- Accept unstructured text.
- Extract fields into JSON.
- Validate required fields.
- Flag uncertain values.
- Store results for review.

Skills practiced:

- Structured outputs.
- Prompt design.
- Validation.
- Human-in-the-loop review.

## Project 4: AI Agent for Research

Build a bounded research agent that searches a knowledge base, summarizes findings, and prepares a brief.

Core features:

- Search trusted sources.
- Keep notes from each step.
- Produce a final summary with references.
- Stop after a fixed number of tool calls.
- Request human approval before external actions.

Skills practiced:

- Agents.
- Tool use.
- Guardrails.
- Evaluation.

## Final Project Checklist

Every capstone should include:

- A clear problem statement.
- A diagram or description of the AI workflow.
- Test examples and evaluation results.
- Risk and safety notes.
- A simple deployment plan.
- A short README explaining how to run and improve the project.

## Learning Goal

Learners should finish the course with practical AI projects that show engineering judgment, product thinking, and responsible implementation.
