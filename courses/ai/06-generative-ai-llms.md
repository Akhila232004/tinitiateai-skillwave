# Generative AI and Large Language Models

Generative AI creates new content from instructions, examples, or context. Large language models are generative models trained to process and produce text-like sequences, including natural language, code, tables, and structured formats.

## What Generative AI Can Produce

Generative AI can help with:

- Drafting and rewriting text.
- Summarizing long documents.
- Generating code and tests.
- Extracting structured data from messy input.
- Answering questions from provided context.
- Creating images, audio, or video.
- Assisting users through conversational interfaces.

## LLM Concepts

- Token: a unit of text processed by a model.
- Context window: the amount of input and output the model can handle at once.
- Temperature: a setting that affects randomness.
- System instruction: high-priority behavior guidance.
- Prompt: the user or application instruction.
- Completion: the model output.
- Fine-tuning: training a model further for a specific style or task.

## Generation Is Probabilistic

LLMs do not retrieve truth by default. They predict likely output based on training and context. This makes them flexible, but it also means they can produce incorrect or unsupported answers. Strong AI products use context, constraints, retrieval, evaluation, and user experience design to manage this behavior.

## Common Application Patterns

- Chat assistant: conversational support for a user.
- Copilot: AI assistance inside a workflow.
- Extractor: converts unstructured content into structured JSON or tables.
- Summarizer: compresses information while keeping key facts.
- RAG assistant: answers using retrieved documents.
- Agentic workflow: uses tools to complete tasks with bounded autonomy.

## Learning Goal

Learners should understand what generative AI is good at, where it can fail, and how LLM concepts shape application design.
