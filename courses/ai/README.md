# AI Course

![AI course visual](../../design/course-icons/ai.png)

This course is authored directly inside the Tinitiate education content repository. It teaches artificial intelligence from the ground up, then moves into practical engineering workflows for machine learning, generative AI, retrieval-augmented generation, agents, evaluation, safety, and production delivery.

## CONTENTS

## [AI Foundations](./01-ai-foundations.md)
- Understand what artificial intelligence is and where it is useful.
- Learn the difference between AI, machine learning, deep learning, and generative AI.
- Build the vocabulary needed for the rest of the course.

## [Problem Framing for AI](./02-problem-framing.md)
- Convert business goals into AI tasks.
- Decide whether classification, prediction, search, generation, or automation is the right fit.
- Define success metrics before choosing tools.

## [Data for AI](./03-data-for-ai.md)
- Learn how data quality shapes model quality.
- Prepare, label, split, and document datasets.
- Avoid leakage, bias, and weak evaluation data.

## [Machine Learning Core](./04-machine-learning-core.md)
- Learn supervised, unsupervised, and reinforcement learning at a practical level.
- Understand features, labels, training, validation, and inference.
- Compare common models and know when to use them.

## [Deep Learning and Neural Networks](./05-deep-learning-neural-networks.md)
- Learn how neural networks represent patterns.
- Understand embeddings, activations, loss functions, and optimization.
- Connect deep learning to vision, speech, language, and recommendation systems.

## [Generative AI and Large Language Models](./06-generative-ai-llms.md)
- Understand how generative models produce text, code, images, and structured outputs.
- Learn core LLM concepts such as tokens, context windows, temperature, and fine-tuning.
- Use generative AI responsibly in real applications.

## [Prompt Engineering](./07-prompt-engineering.md)
- Write clear prompts with role, task, context, constraints, and examples.
- Use structured outputs, decomposition, and verification prompts.
- Reduce hallucination and ambiguity.

## [RAG and Vector Search](./08-rag-vector-search.md)
- Build retrieval-augmented generation workflows.
- Use embeddings, vector databases, chunking, retrieval, and citations.
- Improve answers with better context design.

## [AI Agents and Tool Use](./09-ai-agents-tools-workflows.md)
- Understand agents, tools, planners, and workflow orchestration.
- Design bounded AI automation that can inspect, decide, and act.
- Add guardrails for tool calls and human approval.

## [Evaluation, Safety, and Ethics](./10-ai-evaluation-safety.md)
- Evaluate model quality with tests, rubrics, examples, and monitoring.
- Identify privacy, bias, security, and misuse risks.
- Design safer AI experiences for real users.

## [Production AI and MLOps](./11-production-ai-mlops.md)
- Deploy AI systems with reliability, observability, and cost control.
- Manage model versions, prompts, datasets, and rollback plans.
- Monitor drift, latency, failures, and user feedback.

## [Capstone Projects](./12-capstone-projects.md)
- Build portfolio-ready AI projects.
- Practice end-to-end design from problem to deployment.
- Combine prompts, RAG, evaluation, and production thinking.

## Conclusion

By the end of this course, learners should be able to design useful AI features, choose the right technique, build a reliable prototype, evaluate quality, and prepare an AI system for production use.
