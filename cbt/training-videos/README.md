# Training Videos

This folder stores training-video metadata for the CBT section.

## Goal

Allow the website to fetch video collections from GitHub instead of hardcoding them in the frontend.

## Structure

- `av-metadata.yaml`
- optional notes in `collections/*.md`

## How To Add A New Training Video Collection

1. Add an item in `av-metadata.yaml`
2. Add a markdown notes file if needed
3. Provide a valid source or embed URL
