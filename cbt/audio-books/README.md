# Audio Books

This folder stores audio-learning metadata for the CBT section.

## Goal

Support audio-first learning collections such as:

- concept recap audio
- spoken walkthroughs
- revision playlists
- interview listening guides

## Structure

- `av-metadata.yaml`
- optional notes in `collections/*.md`

## How To Add A New Audio Collection

1. Add the metadata entry
2. Add optional notes markdown
3. Use a valid source URL or embed URL
