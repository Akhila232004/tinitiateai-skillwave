# React State Basics
## What is State?

- State is data owned by a component
- State changes trigger UI updates
- Use state for interactive and dynamic behavior
![React State](images/react-state.png)

---

## Simple Flow

1. User takes an action
2. Component updates state
3. React re-renders the UI
4. Updated values move through the component tree

---

## Best Practices

- keep state close to where it is used
- avoid duplicate sources of truth
- derive computed values when possible
- lift state only when needed
